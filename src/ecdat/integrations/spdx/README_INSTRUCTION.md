# IMPLEMENTATION CONTRACT — SPDX Interoperability

SPDX 3.0 is a **secondary interoperability target**, not ECDAT's canonical internal schema and not the primary CBOM representation.

Implement import/export only after mapping requirements are validated against the current SPDX 3.0 model. Do not force ECDAT crypto-specific evidence into lossy fields merely to claim compatibility. Document unsupported mappings.
